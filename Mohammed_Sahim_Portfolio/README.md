## 🚀 How to Run Locally

### Option 1: Double Click
Simply double-click `index.html` to open it in any modern web browser.

### Option 2: Local HTTP Server (Python)
If you have Python installed:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

## ☁️ How to Deploy to Vercel

### Method A: One-Click Script (Easiest)
1. Double-click `deploy-vercel.bat` in this folder (or run `.\deploy-vercel.ps1` in PowerShell).
2. It will log you into Vercel (if not already logged in) and deploy your site to production immediately.

### Method B: Terminal (Vercel CLI)
Open your terminal in this directory and run:
```bash
vercel login
vercel --prod
```

### Method C: Vercel Web Dashboard (Via GitHub)
1. Push this folder to a GitHub repository (e.g. `github.com/MohammedSahim/portfolio`).
2. Go to [vercel.com](https://vercel.com) and log in with GitHub.
3. Click **"Add New..."** > **"Project"** and import your repository.
4. Click **Deploy**. Vercel will build and assign you a free `*.vercel.app` URL with automatic deployments on git push!
